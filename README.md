# nRF52840 Bluetooth SoC

This repository documents my learning and hands-on exploration of the **nRF52840 Bluetooth System-on-Chip (SoC)** and its applications in **wearable technology**. The goal of this project is to build a strong foundational understanding of the nRF52840 while supporting my **university design team**, **UofT Wearable**.

Throughout this repository, I work with the nRF52840 using **Embedded C** and the **nRF Connect SDK**, gradually progressing from core concepts to practical implementations. The long-term objective is to design and develop a functional **wearable application** based on this Bluetooth SoC.
